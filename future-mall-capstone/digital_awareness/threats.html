Cyber Threat Library

Understand the 8 major cyber threats and how to protect yourself

Major Cyber Threats

Click on any threat to learn more about how it works and how to protect yourself

🎣

Phishing

High Risk

Fraudulent attempts to obtain sensitive information by disguising as a trustworthy entity in electronic communications.

Common Examples:

  • Fake bank emails asking to "verify" account
  • Fake login pages for popular services
  • SMS/text messages with malicious links (smishing)
  • Voice calls pretending to be tech support (vishing)

Warning Signs:

  • Urgent or threatening language
  • Generic greetings ("Dear Customer")
  • Poor grammar, spelling, or formatting
  • Requests for personal/financial information
  • Suspicious sender addresses

Prevention:

  • Verify sender through official channels
  • Don't click links in unexpected emails
  • Hover over links to check real destination
  • Enable 2FA on all accounts
  • Report phishing to your IT/security team
🦠

Malware

High Risk

Malicious software designed to disrupt, damage, or gain unauthorized access to computer systems.

Types:

  • Trojans - Disguised as legitimate software
  • Worms - Self-replicating network spreaders
  • Rootkits - Hide deep in system
  • Keyloggers - Record keystrokes

Warning Signs:

  • Slow system performance
  • Unexpected pop-ups or ads
  • Programs opening/closing automatically
  • Browser redirects
  • Disabled antivirus

Prevention:

  • Keep OS and software updated
  • Use reputable antivirus/anti-malware
  • Don't download from untrusted sources
  • Be cautious with email attachments
  • Use standard user account (not admin)
🦠

Viruses

High Risk

Self-replicating malicious code that attaches to legitimate programs and spreads when executed.

Characteristics:

  • Requires host program to execute
  • Replicates by modifying other files
  • Can corrupt or delete data
  • Spreads via infected files/media

Warning Signs:

  • Files changing size unexpectedly
  • Programs taking longer to start
  • Unexplained disk activity
  • System crashes or freezes

Prevention:

  • Real-time antivirus protection
  • Scan downloads before opening
  • Don't run unknown executables
  • Keep backups of important data
💰

Ransomware

Critical Risk

Malware that encrypts files and demands payment (ransom) for decryption key.

How it works:

  • Encrypts files with strong encryption
  • Displays ransom note with payment instructions
  • Often demands cryptocurrency payment
  • May threaten to leak data (double extortion)

Warning Signs:

  • Files with new extensions (.encrypted, .locked)
  • Ransom notes on desktop or in folders
  • Unable to open previously accessible files
  • Desktop wallpaper changed to ransom note

Prevention:

  • Regular offline backups (3-2-1 rule)
  • Email attachment scanning
  • Network segmentation
  • Patch management
  • User training on phishing
👁️

Spyware

High Risk

Software that secretly monitors user activity and collects personal information without consent.

What it steals:

  • Keystrokes (passwords, messages)
  • Browsing history and habits
  • Personal files and documents
  • Webcam/microphone access
  • Location data

Warning Signs:

  • Unexplained data usage
  • Battery draining quickly
  • Webcam light on unexpectedly
  • Strange apps installed

Prevention:

  • Anti-spyware software
  • Review app permissions regularly
  • Cover webcam when not in use
  • Don't install unknown apps
🆔

Identity Theft

Critical Risk

Fraudulent use of someone's personal information for financial gain or other crimes.

Methods:

  • Data breaches exposing personal info
  • Phishing for SSN, DOB, addresses
  • Dumpster diving for documents
  • Social media oversharing

Warning Signs:

  • Unfamiliar charges on statements
  • Credit report changes
  • Denied credit applications
  • IRS notices about unknown income

Prevention:

  • Monitor credit reports regularly
  • Freeze credit when not needed
  • Shred sensitive documents
  • Limit personal info sharing online
  • Use identity theft protection services
📊

Data Breaches

High Risk

Unauthorized access to confidential data, often exposing personal information of millions of users.

Causes:

  • Weak security configurations
  • Unpatched vulnerabilities
  • Insider threats
  • Third-party vendor compromises

Impact:

  • Exposed passwords, emails, PII
  • Financial fraud and identity theft
  • Reputational damage to organizations
  • Legal and regulatory penalties

Protection:

  • Use unique passwords per site
  • Enable breach monitoring (HaveIBeenPwned)
  • Change passwords immediately after breach
  • Use password managers
🎭

Social Engineering

High Risk

Psychological manipulation to trick people into revealing confidential information or performing actions.

Techniques:

  • Pretexting - Fabricated scenario to gain trust
  • Baiting - Enticing with false promises
  • Tailgating - Following authorized person into restricted area
  • Quid pro quo - Offering service for information

Warning Signs:

  • Unsolicited requests for sensitive info
  • Pressure to act quickly
  • Too-good-to-be-true offers
  • Requests to bypass security procedures

Prevention:

  • Verify identity through independent channels
  • Follow security protocols strictly
  • Report suspicious interactions
  • Regular security awareness training

Threat Summary

Quick reference for threat severity and key defenses

Threat Severity Primary Target Key Defense
Phishing High Credentials, Financial Info Verify sender, 2FA, Hover links
Malware High System Integrity, Data Antivirus, Updates, Caution
Viruses High Files, System Antivirus, Backups, Caution
Ransomware Critical Files, Operations Offline Backups, Email Security
Spyware High Privacy, Credentials Anti-spyware, Permissions
Identity Theft Critical Personal Identity, Finances Credit Monitoring, Privacy
Data Breaches High Exposed Personal Data Unique Passwords, Monitoring
Social Engineering High Human Psychology Verification, Training, Protocols

Universal Protection Checklist

Apply these practices to defend against all threats

🔐 Account Security

  • Use unique 12+ character passwords for each account
  • Enable 2FA/MFA on all important accounts
  • Use a reputable password manager
  • Monitor for data breaches (HaveIBeenPwned)
  • Set up account recovery options

💻 Device Security

  • Enable automatic OS and software updates
  • Install reputable antivirus/anti-malware
  • Enable firewall
  • Encrypt device storage (BitLocker/FileVault)
  • Use standard user account (not admin)

🌐 Network & Browsing

  • Use HTTPS everywhere (HTTPS Everywhere extension)
  • Avoid public Wi-Fi for sensitive activities (use VPN)
  • Verify URLs before entering credentials
  • Clear browser data regularly
  • Use ad/tracker blocker

📧 Email & Communication

  • Verify sender before clicking links
  • Don't open unexpected attachments
  • Report phishing to IT/security team
  • Use separate email for sensitive accounts
  • Be wary of urgent/threatening language

💾 Data Protection

  • Follow 3-2-1 backup rule
  • Test backup restores quarterly
  • Encrypt sensitive files
  • Shred physical documents
  • Limit personal info sharing online

🛡️ Awareness & Habits

  • Stay informed about current threats
  • Complete security awareness training
  • Report suspicious activity immediately
  • Question urgent/unusual requests
  • Teach family/friends basic security
