About Future Mall

A comprehensive capstone project integrating 7 educational modules

🎯

Purpose

Future Mall demonstrates mastery of software engineering, web development, branding, data analysis, cybersecurity awareness, and professional documentation through a cohesive, real-world project.

🏬

5 Stores

  • Tech Planet - Electronics
  • Fashion Avenue - Clothing
  • Fresh Basket - Supermarket
  • HomeWorks - Furniture
  • Kids Kingdom - Toys & Games
🎨

Design System

Consistent Future Mall branding across all modules using Space Grotesk and Inter typography with a navy/blue/orange color palette.

🚀

Deployment

GitHub Pages deployment with automated CI/CD pipelines for web modules. Python modules packaged as executables for easy distribution.

Project Modules

Seven integrated modules showcasing diverse technical skills

💰

Cashier Program

Console-based shop simulator with product catalog, shopping cart, discounts, tax calculation, and professional receipt generation.

  • Product catalog with 10 items
  • Cart management (add/remove/update)
  • Tiered discounts (5%/10%/15%)
  • Receipt generation & file export
Python Console
📊

Visitors Analysis

Statistical analysis of weekly visitor data with total, average, min/max, median, range, and percentage change calculations.

  • 7-day data collection
  • Comprehensive statistics
  • CSV & JSON export
  • Daily trend analysis
Python Console
🏷️

Product Classifier

Multi-dimensional product classification by price (Premium/Standard/Budget), weight (Light/Medium/Heavy), and stock (In/Low/Out of Stock).

  • 3 classification dimensions
  • JSON persistence
  • Search & sort
  • Rule reference
Python Console
⏰

Attendance System

Full-featured Tkinter desktop app with SQLite backend. Role-based dashboards for Employee, Supervisor, and Admin with check-in/out, reports, and analytics.

  • 3 role-based dashboards
  • Check-in/out with validation
  • Daily/weekly/monthly reports
  • CSV/Excel export
Python Tkinter + SQLite
🌐

GitHub Pages Website

Responsive personal portfolio website with semantic HTML5, modern CSS3, dark mode, and automated GitHub Pages deployment.

  • Semantic HTML5
  • Dark mode support
  • Responsive design
  • Auto-deploy CI/CD
HTML/CSS/JS
🛡️

Digital Awareness

Interactive cybersecurity education platform with threat library, password strength checker, phishing quiz, and safety posters.

  • 8 threat categories
  • Password strength meter
  • Phishing identification quiz
  • Downloadable posters
HTML/CSS/JS
