## Quick Reference

- **Colors:** Primary `#2563EB`, Secondary `#0D9488`, Accent `#F97316`
- **Fonts:** Space Grotesk (display) + Inter (body) + JetBrains Mono (code)
- **Tagline:** "Shopping for Tomorrow"
- **Logo:** default horizontal primary lockup; use stacked for squares; icon for small UI

## Usage

1. Read the [Brand Guidelines](BRAND_GUIDELINES.md).
2. Grab assets from the relevant subfolder.
3. Use `shared/constants.css` / `shared/constants.js` in web modules for exact tokens.
